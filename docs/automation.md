# Native 2D automation preview

The [VisiRupt automation source PR](https://github.com/johnrtipton/visirupt/pull/1) publishes the exact-build preparation and explicit deployment workflow. The reviewed source revision is `e0aa37e7cd6b60600c433265ceb44a05c8e8a245`; it is a draft PR, separate from the active VR research.

Read the [complete commands and acceptance matrix](https://github.com/johnrtipton/visirupt/blob/e0aa37e7cd6b60600c433265ceb44a05c8e8a245/docs/automation.md). To try that reviewed preview source:

```sh
git clone --branch feat/native-cyberpunk-pipeline https://github.com/johnrtipton/visirupt.git
cd visirupt
git rev-parse HEAD
```

The CLI covers doctor/plan, private preparation and independent verification, own-team build/signing, private original asset manifest with a reviewed arrow-key override, foreground/background transfer with a native owner lease, explicit installation/launch, status and allowlisted report drafts. It requires a matching user-owned Mac2.3 game and visionOS SDK27.0. Workspace, device, transport and signing selectors are explicit. Originals stay untouched and proprietary bytes are never distributed.

For a new receiver, first deployment and launch are explicit flags. Existing installed ownership must be established by this workspace's own completed normal installation and unchanged system bundle URL; unknown manual research installations stop for migration rather than being replaced. Preserve the workspace and receiver/host container. A later host update explicitly requests the receiver verifier round trip to recheck native assets before replacing the host. Never uninstall as a retry.

Validation completed locally:102 Python checks (one private-input test skipped by default and separately passed), Swift receiver/lease controls, six background planning controls, full110 original Data hashes, a fresh ten-framework source prepare/verify/cache-resume on public main's base, and an unsigned host build with embedded semantic checks. Fresh-context code review found two retry defects; both have reproduced regression tests and fixes.

**Pending:** normally provisioned own-team signing, the new CLI's physical transfer/update/launch sequence, independent second-Mac/headset reproduction, audio/save/relaunch, sustained stability and gameplay FPS. Existing human-confirmed native2D gameplay is the baseline, not proof these new automation gates passed. True Cyberpunk VR remains research. No headset was modified during this implementation.
