# Troubleshooting

Diagnose the failed stage before rebuilding, recopying assets or attaching a debugger.

| Symptom | Check / next action |
| --- | --- |
| Clean checkout cannot build | Inspect external provider/module requirements in the engine checkpoint. Source publication currently does not complete their preparation recipe. |
| Transfer pauses | Check native receipts, Mac reachability/awake state and available disk space. Reopen the receiver when necessary; resume verified offsets. Do not run two writers. |
| App update threatens existing data | Preserve the receiver/host identifier and signing/container relationship; back up checkpoints and saves. Do not uninstall as a retry. |
| Installer fails or host disk fills | Inspect installation receipts and temporary space. Stopping a CLI client may leave work in Apple's shared service; avoid blindly launching another install. |
| Missing archive assertion | Verify whole-file hashes and the actual game-visible asset root. Successful bootstrap config opens do not prove archives are accessible. |
| Plain window will not accept pointer | Check the full rectangular interaction area and actual pointer readiness. The accepted host uses a black background/hit region. |
| Keyboard or turning fails | Confirm window focus, actual key down/up delivery and the expected input configuration. Revert to the accepted 2D build if a research build regresses. |
| Larger window still looks low resolution | Read actual drawable dimensions. Window size and saved Resolution settings do not prove render output changed. |
| Debugger attachment freezes/fails | Stop the observation experiment safely and restore ordinary launch. Recheck current process/module identity; never reuse stale IDs or ASLR slides. Preserve other device jobs. |

Capture source revision, game build, stage, exact error, expected/observed behavior and whether a normal relaunch reproduces it. Remove paths, device IDs, credentials and private content before contributing. Report intermittent startup separately from confirmed playable runs.
